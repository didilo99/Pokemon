Esta es una aplicación web interactiva diseñada para entusiastas de Pokémon. Permite gestionar una base de datos propia de criaturas, visualizar sus estadísticas y mantener un registro organizado mediante un sistema CRUD (Create, Read, Update, Delete).

---

## 🌟 Funcionalidades Principales

* **🔍 Búsqueda Dinámica:** Encuentra a tu Pokémon favorito por nombre o ID al instante.
* **📊 Estadísticas Detalladas:** Visualización de puntos de vida (HP), ataque, defensa y tipos.
* **📝 Gestión de Entrenador:** Sistema completo para añadir nuevos Pokémon capturados, editar sus datos o liberarlos (eliminar).
* **🖼️ Galería Visual:** Carga de imágenes para cada Pokémon para una experiencia más inmersiva.
* **🛡️ Validación de Datos:** Formularios protegidos para asegurar que la información guardada sea correcta.

---

## 🛠️ Stack Tecnológico

El proyecto está construido utilizando un stack clásico y robusto para desarrollo web:

| Tecnología | Uso |
| :--- | :--- |
| **PHP 8.x** | Lógica del servidor y procesamiento de datos. |
| **MySQL** | Base de Datos relacional para almacenar los Pokémon. |
| **HTML5 & CSS3** | Estructura y diseño visual moderno. |
| **JavaScript** | Interactividad en el cliente y validaciones. |
| **XAMPP** | Entorno de desarrollo local (Apache + MariaDB). |
